Python per il calcolo numerico#

Questo corso presenta gli algoritmi usati per risolvere in modo efficiente e accurato problemi che coinvolgono vettori e matrici, fornendo approssimazioni numeriche delle soluzioni.

La principale libreria Python per la rappresentazione e la manipolazione efficiente di vettori, matrici e array multidimensionali è NumPy. Durante il corso utilizzeremo frequentemente NumPy insieme a SciPy, che mette a disposizione algoritmi più avanzati per il calcolo scientifico.

Indicheremo generalmente le matrici con lettere maiuscole, come (A, B, …), e i vettori con lettere minuscole, come (x, y, v, w, …).

NOTA: NumPy viene generalmente importato assegnandogli l’alias convenzionale np:

import numpy as np

quindi tutte le sue funzioni saranno richiamate mediante il prefisso np., per esempio:

import numpy as np
x = np.sqrt(2)

print(x)

1.4142135623730951

Installazione e documentatazione#

Se NumPy non è disponibile nell’ambiente Python, può essere installato dal terminale con:

python -m pip install numpy

oppure, in un ambiente Conda, con:

conda install numpy

Per maggiori informazioni è possibile consultare la documentazione ufficiale di NumPy numpy.org.

(1) Numpy ndarray#

L’oggetto principale di numpy è il cosiddetto ndarray, che si usa per definire vettori, matrici e tensori “con proprietà” matematiche

Un modo semplice per definire un ndarray è partire da oggetti python come list o tuple, poi convertirli in oggetto np:

import numpy as np

# Partiamo da una lista Python
a = [1, 2, 3]
print(type(a))

# Converto la lista in un numpy array
a = np.array(a)
print(a, type(a))

# Partiamo da una lista Python
b = (1, 2, 3, 4, 5)
print(type(b))

# Converto la lista in un numpy array
b = np.array(b)
print(b, type(b))

<class 'tuple'>
[1 2 3 4 5] <class 'numpy.ndarray'>

# Caso con una matrice 3x3
A = [[1, 1, -1], [2, 0, 0], [0, 1, 2]]
A = np.array(A)

print(A)
print(A.shape)

  • shape: dimensione dell’array lungo ciascun asse;

  • ndim: numero di dimensioni, o assi, dell’array;

  • size: numero totale di elementi;

  • dtype: tipo numerico degli elementi.

(2) Creazione di vettori e matrici#

Nelle applicazioni reali si lavora spesso con vettori e matrici di grandi dimensioni, che possono contenere milioni di elementi. Non è quindi possibile definirli inserendo manualmente tutti i valori.

Quando i dati seguono una struttura particolare, NumPy mette a disposizione diverse funzioni per creare gli array in modo semplice ed efficiente.

  • np.linspace(a, b, n): crea un vettore contenente n valori equidistanti nell’intervallo chiuso \([a,b]\), estremi inclusi.

  • np.arange(start, end, step): crea un vettore di valori compresi tra start incluso e end escluso, con incremento step.

  • np.zeros((m, n)): crea una matrice \(m \times n\) contenente solo zeri. Nel caso di np.zeros((m, )) si ottiene un vettore.

  • np.ones((m, n)): crea una matrice \(m \times n\) contenente solo elementi uguali a uno.

  • np.zeros_like(a): crea un array di zeri con la stessa forma e lo stesso tipo di dato di a. Analogamente, si può usare np.zeros(a.shape).

  • np.random.randn(m, n): crea una matrice \(m \times n\) i cui elementi sono estratti indipendentemente da una distribuzione normale standard \(\mathcal{N}(0, I)\).

  • np.eye(n): crea la matrice identità di ordine n.

  • np.diag(v): dato un vettore v di shape (n,), crea una matrice diagonale \(n \times n\) i cui elementi diagonali sono quelli di v.

c = np.linspace(0, 1, 5) # array([0. , 0.25, 0.5 , 0.75, 1. ])
print(c)

d = np.arange(0, 20, 2)
print(d)

E = np.zeros((2, 3))
print(f"E={E}\n")

f = np.ones((6, ))
print(f)

g = np.zeros_like(d)
print(g)

rng = np.random.default_rng(42) 
H = rng.standard_normal((2, 3))
print(f"H={H}\n")

I = np.eye(3)
print(f"I={I}\n")

v = np.array([1, 2, 3]) 
L = np.diag(v)
print(f"L={L}")

(3) Funzioni elemento-per-elemento su ndarray#

Molte funzioni NumPy hanno un corrispondente tra le funzioni di base di Python o nel modulo math, ma sono progettate per lavorare elemento per elemento sugli array.

x = np.array([1, 4, 9, 16])

# Funzioni base
np.sqrt(x)   # al posto di math.sqrt()
print(np.sqrt(x))
np.exp(x)    # al posto di math.exp()
np.log(x)    # al posto di math.log()
np.sin(x)    # al posto di math.sin()
np.cos(x)    # al posto di math.cos()
np.abs(x)    # analoga ad abs()

# Operazioni di aggregazione
np.sum(x)     # analoga a sum()
np.min(x)     # analoga a min()
np.max(x)     # analoga a max()
np.mean(x)    # media
np.std(x)     # deviazione standard
print(np.std(x)) 

[1. 2. 3. 4.]
5.678908345800274

A = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print( np.sum(A) )          # 21
print( np.sum(A, axis=0) )  # array([5, 7, 9]): somma per colonne
print( np.sum(A, axis=1) )  # array([6, 15]): somma per righe

21
[5 7 9]
[ 6 15]

Nota: Mentre le liste sono strutture Python generiche e progettate per raccogliere anche oggetti di tipo diverso, gli array NumPy contengono invece elementi generalmente omogenei e sono progettati per eseguire operazioni numeriche vettoriali in modo compatto ed efficiente.

Ne deriva che lo stesso operatore può assumere significati diversi a seconda del tipo di oggetto sul quale viene applicato!

Esemmpio 1:

  • Per una lista Python, la moltiplicazione per un intero ripete gli elementi della lista;

  • Per un array NumPy, invece, la moltiplicazione per uno scalare viene applicata elemento per elemento.

# Attenzione!
x = [1, 2, 3]     # lista

x2 = x * 2             # [1, 2, 3, 1, 2, 3]
print(x2, type(x2))

x2 = np.array(x) * 2   # array([2, 4, 6])
print(x2, type(x2))

[1, 2, 3, 1, 2, 3] <class 'list'>
[2 4 6] <class 'numpy.ndarray'>

Esempio 2:

  • Per una lista Python, la somma di liste è una concatenazione;

  • Per un array NumPy, invece, la somma viene calcolata elemento per elemento.

a = [1, 2, 3] 
b = [4, 5, 6]      

print(a+b)                          # concatenazione
print( np.array(a)+np.array(b) )    # somma elemento per elemento

[1, 2, 3, 4, 5, 6]
[5 7 9]

(4) Operazioni fra vettori e matrici#

Per semplificare l’implementazione degli algoritmi di algebra lineare numerica, le operazioni fra gli array NumPy seguono essenzialmente la stessa sintassi utilizzata nei testi di matematica. Quindi, anche tutte (o quasi) le operazioni fra vettori e matrici vengono applicate elemento per elemento.

Un’operazione fra due array \(n\)-dimensionali \(a\) e \(b\) si dice elemento per elemento quando viene applicata separatamente a ogni coppia di elementi corrispondenti di \(a\) e \(b\).

Per esempio, consideriamo i vettori: \( a = \begin{bmatrix} 1 \\ 0 \\ -1 \end{bmatrix} \qquad b = \begin{bmatrix} 0 \\ 2 \\ 2 \end{bmatrix} \) e la loro somma element-wise è: \(a + b = \begin{bmatrix} 1 + 0 \\ 0 + 2 \\ -1 + 2 \end{bmatrix} = \begin{bmatrix} 1 \\ 2 \\ 1 \end{bmatrix}. \)

Vediamo ora le principali operazioni elemento per elemento, fra due generici array NumPy a e b che hanno la stessa shape (vettori o matrici).

  • a + b: restituisce la somma elemento per elemento di a e b.

  • a - b: restituisce la differenza elemento per elemento fra a e b.

  • a * b: restituisce il prodotto elemento per elemento di a e b.

  • a / b: restituisce il quoziente elemento per elemento fra a e b.

  • a ** b: eleva ogni elemento di a alla potenza indicata dal corrispondente elemento di b.

Nell’algebra lineare numerica sono particolarmente importanti le operazioni di:

  • prodotto matrice-vettore;

  • prodotto matrice-matrice;

  • prodotto scalare fra vettori. Poiché queste operazioni sono strettamente collegate dal punto di vista matematico, NumPy utilizza per tutte lo stesso operatore @: se le shape di due array a e b sono compatibili, a @ b esegue il loro prodotto corrispondente.

import numpy as np

# Dimension of the problem
n = 10

# Create the vectors
x1 = np.linspace(0, 1, n)
x2 = np.random.randn(n)

# Create the matrix
A = np.random.randn(n, n)

# Compute y1 and y2
y1 = A @ x1
y2 = A @ x2

# Compute y = A(x1 + x2)
y = A @ (x1 + x2)

# Check the equality
print(y)
print(y1 + y2)

(5) Slicing#

Un’operazione importante, anche qua, è il cosiddetto slicing. Lo slicing permette di estrarre una porzione di un array specificando gli indici degli elementi che vogliamo selezionare.

Dato un vettore v, usiamo la notazione v[start:end:step] come per gli oggetti di Python.

# Creazione dell'array
v = np.array([0, 3, -4, 2, 1, 7])
print(v)

# Slicing
print(v[1:3])
print(v[:3])
print(v[3:])
print(v[-1])

print(v[::2])
print(v[::-1])

[ 0  3 -4  2  1  7]
[ 3 -4]
[ 0  3 -4]
[2 1 7]
7
[ 0 -4  1]
[ 7  1  2 -4  3  0]

Possiamo selezionare elementi non necessariamente consecutivi passando tra parentesi quadre un array contenente gli indici desiderati. Questa operazione è detta più precisamente indicizzazione avanzata (advanced indexing).

# Creazione degli indici 0, 2 e 4 
idx = np.arange(0, len(v), 2)
print("Indici selezionati:", idx) 

# Selezione degli elementi
print("Elementi selezionati:", v[idx] )

Indici selezionati: [0 2 4]
Elementi selezionati: [ 0 -4  1]

Inoltre, possiamo fare slicing usando un array booleano. In questo caso , solo gli elementi corrispondenti ai True sono considerati.

# Creo i vettori
v = np.array([0, 3, -4, 2, 1, 7])
w = np.array([0, 0, -4, 1, 8, 7])

# Slicing
t = v[v == w]   # la mappa booleana è data dai valori uguali
print(v)
print(w)
print(t)

[ 0  3 -4  2  1  7]
[ 0  0 -4  1  8  7]
[ 0 -4  7]

Lo slicing su matrici funziona come per i vettori, ma servono array di indici bi-dimensionali.

print(A)

# Slicing
B = A[:3, :2]
print(B)

(6) Il sottomodulo numpy.linalg#

NumPy mette a disposizione il sottomodulo numpy.linalg, che contiene numerose funzioni per eseguire operazioni di algebra lineare su vettori e matrici.

In questo corso saranno particolarmente utili le seguenti funzioni:

  • np.linalg.norm(a, ord=p): calcola la norma di ordine \(p\) del vettore a. La stessa funzione può essere applicata anche alle matrici, specificando una delle norme matriciali disponibili.

  • np.linalg.cond(A, p=p): calcola il numero di condizionamento della matrice A rispetto alla norma indicata.

  • np.linalg.matrix_rank(A): calcola il rango della matrice A.

  • np.linalg.inv(A): calcola la matrice inversa di A, se questa esiste.

Il sottomodulo contiene inoltre funzioni per risolvere sistemi lineari e calcolare autovalori e autovettori:

  • np.linalg.solve(A, b): risolve il sistema lineare \(Ax=b\).

  • np.linalg.eig(A): calcola gli autovalori e gli autovettori della matrice quadrata A.

  • np.linalg.eigh(A): calcola gli autovalori e gli autovettori di una matrice reale simmetrica o complessa hermitiana.

  • np.linalg.svd(A): calcola la decomposizione ai valori singolari di A.

Altre operazioni utili sugli array, pur non appartenendo al sottomodulo numpy.linalg, sono:

  • np.transpose(A): calcola la matrice trasposta di A. È equivalente a A.T

  • np.reshape(a, new_shape): modifica la forma dell’array a, senza cambiarne gli elementi, purché il numero complessivo di elementi rimanga invariato. È equivalente a a.reshape(new_shape)

print(A)
print(A.shape)          # (4, 3)
print(A.T)
print(A.T.shape)        # (3, 4)
